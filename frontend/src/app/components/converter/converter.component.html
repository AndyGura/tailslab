About Conversion

This tool allows you to convert NFS resource files to common formats. Select an input directory or file and an output directory, then click "Convert Files" to start the conversion process.

The converter will process all files in the input directory (including subdirectories) and save the converted files to the output directory.

You can customize conversion settings by expanding the "Conversion Settings" panel. The paths and settings are saved right away, to the selected conversion preset, or to the default ones with "{{ noPresetName }}" selected.

Presets keep several sets of paths and settings: "New preset" copies the current ones to a new preset and selects it. The command line converter uses a preset with --preset "Preset name", with the preset's input and output paths unless they are given, and the default settings without it.
