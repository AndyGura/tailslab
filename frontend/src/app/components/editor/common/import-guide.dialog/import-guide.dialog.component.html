Importing a 3D model from OBJ

The OBJ of the folder you pick next replaces this model. Start from a folder this app exported (the download button) and keep its files together: geometry.obj, material.mtl, geometry_extra.json (the drawing order the game needs; without it the model still imports, with tiny differences) and assets/ (the textures).

Blender

  • File › Import › Wavefront (.obj) with the default settings.
  • Edit, then File › Export › Wavefront (.obj) with the default settings, over geometry.obj in the same folder: when a folder holds several OBJ files, geometry.obj is the one imported.

Materials

  • A textured material is named after a bitmap of the model's FSH, 4 characters at most (rsid), or its image file has such a name. An image that differs from the FSH bitmap replaces it, a new name adds a bitmap.
  • flat_rrggbb: one colour (hex RGB), no texture.
  • <bitmap>__cutout / <bitmap>__opaque: the transparent pixels of the bitmap are skipped / painted.

Objects

  • The game draws a model's parts in three groups, inside, surface, outside, sorting by depth only within a group. A new part goes to surface: end its object name with __outside to draw it over the body (a spoiler, mirrors), with __inside to draw it under.
  • Car wheels are the objects lbl__lt_frnt, lbl__rt_frnt, lbl__lt_rear, lbl__rt_rear: the game puts the tyre textures on them and steers the front ones.
  • Faces with more than 4 corners are split into triangles: keep them convex.

Car files (CFM)

  • A car has two models: the first one is drawn close, the second one far away. Import each one separately.
  • The import changes the opened file in memory: save the file to write it.
